# CLAUDE.md

Electron Mac app plus CLI. Shared code is in `src/`; `main.js` and `cli.js` are thin.

- Renderer is sandboxed with context isolation and a CSP. It reaches Node only through `preload.js`; add an `ipcMain.handle` in `main.js` and a line in `preload.js` for anything new. No inline `style=`.
- `~/.config/sldl/sldl.conf` holds the Soulseek password. Never print, log or commit it. Tests use `SLDL_CONF` and a fake sldl via `SLDL_BIN`.
- `src/devices.js` is read-only. `src/ipod.js` + `tools/ipod_add.py` are the only code that writes to an iPod (pygpod in `~/.config/sldl/venv`, set up by `sldl-dl ipod-setup`). Back up `iPod_Control/iTunes` and `Device` before testing writes, and ask Jack before any new kind of write.
- Design follows the Invoice app (`../invoice-generator`): glass sidebar, grouped rows, amber accent from the logo. Check UI with `npx electron test/shot.js <dir>`.
- Spotify and Soulseek credentials are not set on this Mac since the logic board wipe, so real downloads are untested.
- Release: `npm run release` (`tools/release.sh`) builds, signs (Developer ID, hardened runtime), notarises and staples the DMG and zip in `dist/`. Uses the keychain profile `notary` (re-create with `xcrun notarytool store-credentials notary --apple-id <id> --team-id <team>`; the Apple ID and team are in Jack's own notes, not in this public repo). `npm run build` alone signs but does not notarise. Images the app shows must live in `assets/`, not `build/` (electron-builder leaves `build/` out of the package). Entitlements are in `build/entitlements.mac.plist`; `tools/` is asar-unpacked so Python can read it. Installed copy: `/Applications/myPod.app` (the app was renamed from SLDL Downloader; the bundle id `com.jackm.sldl-downloader`, the repo and the CLI keep their names so macOS keeps the Music automation permission).
- Files: `src/library.js` (clone, file into iPod folder and library), `src/dedupe.js` (index by title and artist), `src/plan.js` (one planned playlist). iPod folder = `New Downloads` (always MP3), Mac library = `~/Music/Playlists` (chosen format), clones where files match, DJ FLAC kept only in the library, `--only` playlists in one folder. Never leave the only copy of a track in a temp folder.
- `tools/ipod_reconnect.py` resets an ejected iPod over USB so it mounts again (libusb reports "Entity not found" on success). Only ever run it on an iPod with no volume mounted, and not during a send.
- iPods are mounted only for the upload: `ipod.withMounted(serial, fn)` reconnects, runs, then ejects (even on failure). Never write to an iPod outside it, and pick the device with `ipod.resolveDevice` (never "the first one with a volume").
- Before downloading for an iPod, check its stored song list (`known.loadCatalog(serial)`, passed to `dedupe.buildIndex` as `catalog`) so songs it has are linked, not downloaded. `withMounted` refreshes the list on every mount.
